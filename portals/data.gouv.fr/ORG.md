# Organisation data.gouv.fr

- Nom : Weatheo (by CODELIO)
- Site web : https://weatheo.com
- Description (60 mots) :

Weatheo (by CODELIO) est un site de prévisions météo et de données climatiques pour les communes. Nous publions en données ouvertes, sous licence CC BY 4.0, des normales climatiques 1991-2020 et l'évolution du climat depuis 1961-1990, calculées à partir des réanalyses Copernicus ERA5-Land. Les scripts de construction sont ouverts (licence MIT) : https://github.com/weatheo-com/climate-data.
