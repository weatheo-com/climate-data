# Summer 2026 heat report, Europe

Open data behind the Weatheo article: <https://weatheo.com/en/blog/summer-2026-europe-heat-report>

- **Period covered:** 1 June to 31 August 2026 (92 days)
- **Cities:** 32 (one row per city)
- **File:** `summer-2026-europe.csv` (UTF-8, comma separated, header row, RFC 4180)

## Columns

| Name | Type | Unit | Definition |
|---|---|---|---|
| `city` | text | - | City name as shown on weatheo.com. |
| `country` | text | ISO 3166-1 alpha-2 | Country code, upper case. |
| `latitude` | number | degrees north | City-centre latitude used to query the ERA5 grid. |
| `longitude` | number | degrees east | City-centre longitude used to query the ERA5 grid. |
| `days` | integer | days | Number of days in the period covered for this city. |
| `era5_mean_temp_c` | number | °C | Mean of the daily mean 2 m air temperature over the period, rounded to 0.1. |
| `era5_2011_2025_mean_temp_c` | number | °C | Baseline: for each calendar day of the period, the mean of that day's daily mean temperature over the years 2011-2025, then averaged over the period. The 2011-2025 window is a 15-year recent baseline, warmer than a 1961-1990 reference. |
| `era5_anomaly_c` | number | °C | era5_mean_temp_c minus era5_2011_2025_mean_temp_c (positive = warmer than the 2011-2025 baseline). |
| `era5_days_max_30c_plus` | integer | days | Days whose daily maximum temperature is >= 30 °C. |
| `era5_days_max_35c_plus` | integer | days | Days whose daily maximum temperature is >= 35 °C. |
| `era5_nights_min_20c_plus` | integer | nights | Tropical nights: days whose daily minimum temperature is >= 20 °C. |
| `era5_frost_days` | integer | days | Frost days: days whose daily minimum temperature is below 0 °C. |
| `era5_highest_c` | number | °C | Highest daily maximum temperature in the period. |
| `era5_highest_date` | date | YYYY-MM-DD | Date of that highest daily maximum. |
| `era5_lowest_c` | number | °C | Lowest daily minimum temperature in the period. |
| `era5_lowest_date` | date | YYYY-MM-DD | Date of that lowest daily minimum. |
| `forecast_page` | URL | - | Absolute link to the city's forecast page on weatheo.com. |

Empty cells mean no value. Temperatures are rounded to 0.1 °C. Day counts use the daily maximum or minimum of the ERA5 hourly series for the city's local calendar day.

## Source

ERA5 reanalysis, Copernicus Climate Change Service (C3S), retrieved through the Open-Meteo Historical Weather API (<https://open-meteo.com/en/docs/historical-weather-api>). Contains modified Copernicus Climate Change Service information.

## Method

For each city the daily mean, maximum and minimum 2 m temperature were requested for the period and for the baseline years 2011-2025, using the city-centre coordinates and the city's local time zone. The anomaly is the period mean minus the 2011-2025 baseline for the same calendar days. Counts (days >= 30 °C, >= 35 °C, tropical nights, frost days) are taken from the daily series. Full description: <https://weatheo.com/en/blog/methodology> (French: <https://weatheo.com/fr/blog/methodology>). The file is regenerated by `scripts/build.mjs`.

## Limitations

- ERA5 is a reanalysis on a grid of about 0.25 degrees (roughly 25 km), served by Open-Meteo at about 9-25 km: each value describes a grid cell, not a weather-station measurement. Dense city centres and coastal or mountain cities can differ from a local station by several degrees on individual days.
- Coordinates are the city centre; the grid cell may include surrounding countryside, water or relief.
- The baseline is 2011-2025 only, so anomalies are small compared with a 20th-century reference.
- ERA5 lags real time by about five days; the period ends on the last day available for all cities.

## Removed columns

The website's own CSV also contains columns derived from OpenWeather data (prefix `owm_`) and a derived `sources_agree_within_1c` flag. They are **not** included here: OpenWeather's licence does not allow open redistribution, and its record, rain and sunshine values are known to be unreliable. Only ERA5-derived columns and city metadata are published.
